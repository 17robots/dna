## Rows without a visible effect (2026-11-14 run)

| Keys | Why |
| --- | --- |
| `=` | Not implemented: Helix formats the selection through the language server's range formatting. Use `:format` for the configured formatter. |
| `<C-c>` | Intentional difference: Ctrl-C copies in DNA. Use `:comment` or `Space c` to toggle comments. |
| `i <C-s>` | Works, with nothing to see: it closes the current undo step. |
| `*`, `<A-*>` | Work, with nothing to see: they set the search pattern for `n` / `N` (the `* n` row responds). |
| `<A-o> <A-i>` | Needs a grammar; this run installs none (`<A-o>` alone reports that). |
| `x <A-x>` | The fixture's selection is already whole lines, so shrinking changes nothing. |
| `% S <A-K>` | The fixture's split prompt is still open when Alt-K arrives. |
| `z b`, `z m` | The fixture's cursor line is already at the bottom of the view, and its lines are too short to scroll sideways. |
| `g n`, `g p` | The fixture has one buffer, so there is no other buffer to switch to. |
| `l m i w` | The fixture's cursor lands on punctuation, whose inner object is the same single character. |
| `<C-w> s <C-w> j` | Focus moves, but the focused pane is shown only by color, which this text comparison cannot see. |
